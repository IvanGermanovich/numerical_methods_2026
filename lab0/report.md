### 3. Програма `main.py`

Програма виводить «Hello, world» та демонструє основні конструкції Python:
змінні, масиви NumPy, функції, цикли та умовні оператори.

```python
import numpy as np


def f(x):
    return x**2 - 4*x + 3


def main():
    print("Hello, world")

    a = 5
    x = 3.14
    name = "Numerical Methods"

    A = np.array([[1, 2],
                  [3, 4]])
    b = np.array([5, 6])
    print("A @ b =", A @ b)
    print("Розв'язок A x = b:", np.linalg.solve(A, b))

    print("f(1) =", f(1), " f(3) =", f(3))

    for i in range(5):
        print(i)

    if x > 0:
        print("Positive")
    else:
        print("Non-positive")
```

## Відповіді на контрольні питання

**1. Що таке чисельні методи?**
Чисельні методи — це алгоритмічні способи наближеного розв’язування
математичних задач із використанням обчислювальної техніки. Вони оперують
наближеними значеннями, враховують похибку округлення, реалізуються
програмно та орієнтовані на ефективність обчислень.

**2. Які типи задач розв’язуються чисельними методами?**
- розв’язування систем лінійних рівнянь;
- інтерполяція та апроксимація;
- чисельне диференціювання та інтегрування;
- оптимізація;
- розв’язування диференціальних рівнянь.

**3. Які переваги NumPy?**
- ефективні багатовимірні масиви (`ndarray`), що зберігаються компактно в пам’яті;
- векторизовані операції, які виконуються значно швидше за цикли Python
  (реалізація на C);
- готові функції лінійної алгебри (`np.linalg.solve`, `inv`, `det`, `eig`),
  статистики, генерації випадкових чисел;
- зручний синтаксис (індексування, зрізи, broadcasting);
- основа для інших наукових бібліотек (SciPy, Matplotlib, pandas).

**4. Для чого використовується Git?**
Git — розподілена система контролю версій, що дозволяє зберігати історію
змін, працювати з різними версіями коду (гілки, повернення до попередніх
станів) та організувати індивідуальну й командну роботу, зокрема через
віддалені репозиторії (GitHub).

**5. Чому лабораторні необхідно зберігати у системі контролю версій?**
- зберігається повна історія виконання кожної роботи, будь-яку зміну можна
  переглянути або скасувати;
- код захищений від втрати (резервна копія на GitHub);
- усі роботи впорядковані в одному репозиторії, кожна — в окремій папці;
- викладач може легко перевірити роботу та хронологію її виконання;
- формується навичка, необхідна в професійній розробці.
